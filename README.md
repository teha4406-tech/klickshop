# KlikShop — المرحلة 1: الإعداد وتسجيل الدخول وحساب المدير العام

## وظيفة كل ملف
| الملف | وظيفته |
|---|---|
| `index.html` | الصفحة الرئيسية (مؤقتة، الصفحة التسويقية في مرحلة 5) |
| `style.css` | شكل كل الصفحات (عربي RTL) |
| `firebase-config.js` | إعدادات Firebase بتاعتك وتشغيل الخدمات |
| `app.js` | دوال مشتركة: معرفة دور المستخدم، حماية الصفحات، الخروج |
| `login.html` + `login.js` | تسجيل الدخول، وتحويلك للوحة المناسبة لدورك |
| `admin.html` + `admin.js` | لوحة المدير العام (دلوقتي: عدّادات + تأكيد صلاحيتك) |
| `dashboard.html` + `dashboard.js` | لوحة صاحب المحل (دلوقتي: بيانات متجره) |
| `firestore.rules` | **قواعد الأمان الكاملة للمنصة كلها** (بتتلصق في Firebase) |

> مفيش `storage.rules` لأننا مجانيين بدون Storage. صور المنتجات هتتخزن مضغوطة جوه Firestore وتتحمى بنفس القواعد.

## الخطوة 1: رفع الملفات على GitHub (مشروع جديد)
1. https://github.com ← **New repository** ← الاسم `klikshop` ← **Public** ← **Create repository**.
2. **uploading an existing file** ← ارفع كل ملفات المجلد (بالأسماء دي بالظبط، من غير أرقام زي `(1)`).
3. **Commit changes**.
4. **Settings ← Pages ← Branch: `main` / `(root)` ← Save**. بعد دقيقة هتلاقي الرابط:
   `https://teha4406-tech.github.io/klikshop/`

## الخطوة 2: السماح بدومين GitHub في Firebase
مشروع Firebase الجديد (`klick-shop`) لازم تضيف فيه الدومين:
**Authentication ← Settings ← Authorized domains ← Add domain** ← اكتب `teha4406-tech.github.io` (من غير https:// ومن غير اسم المشروع).

## الخطوة 3: لصق قواعد الأمان
**Firestore Database ← Rules** ← امسح كل اللي فيه ← الصق محتوى `firestore.rules` ← **Publish**.

## الخطوة 4: إنشاء حساب المدير العام (إنت)
المدير العام مش بيتعمل من الموقع (عشان محدش يقدر يرقّي نفسه). بتعمله إنت بإيدك مرة واحدة:
1. **Authentication ← Users ← Add user** ← اكتب إيميلك وباسورد قوي ← **Add user**.
2. اضغط على المستخدم اللي اتعمل وانسخ **User UID** (حروف وأرقام طويلة).
3. **Firestore Database ← Data ← Start collection**:
   - Collection ID: `platformAdmins` ← Next
   - Document ID: الصق الـ UID اللي نسخته
   - Field: الاسم `email`، النوع `string`، القيمة إيميلك ← **Save**.

## الخطوة 5: التجربة
1. افتح `https://teha4406-tech.github.io/klikshop/login.html` وادخل بإيميلك.
2. المفروض تفتح **لوحة المدير العام** وفيها ✅ "صلاحية المدير العام مفعّلة" وعدّادات بصفر.
3. **اختبار الرفض:** اعمل مستخدم تاني من **Authentication ← Users** (من غير وثيقة platformAdmins) وجرّب تدخل بيه: المفروض تظهر "حسابك غير مفعّل أو غير مسجّل" وميدخلش.

## الأمان في المرحلة دي
- دور المدير العام بيتحدد من وثيقة `platformAdmins` اللي القواعد بتمنع أي كتابة عليها من الموقع.
- أصحاب المحلات بيتعملوا من لوحتك (مرحلة 2)، ومحدش يقدر يغيّر دوره بنفسه.
- القواعد الكاملة (متاجر، منتجات، تصنيفات، طلبات، باقات) موجودة من دلوقتي عشان متحتاجش تغيّرها كل مرحلة، وهنختبرها بالتفصيل في مرحلة 2.
- **القواعد لسه ما اتجرّبتش على Firebase الحقيقي.** هنعمل اختبارات كاملة (Emulator + قايمة اختبار يدوي) في المراحل الجاية.
